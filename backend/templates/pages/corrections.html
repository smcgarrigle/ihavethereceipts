Remove keeps a lesson out of future prompts. It is not deleted — the decision survives re-saving the receipt it came from, and Restore reverses it at any time.

Pin holds a lesson in its store's prompt regardless of age. Pins fill first, so a pin costs a slot rather than making the prompt larger.

Seen counts how many stored corrections describe this lesson.

Used this week and Last used come from the prompt usage log, which starts from the day usage logging shipped — an older lesson can read never and still have been sent many times.

How many lessons one prompt carries is set by CORRECTION_PROMPT_LIMIT (default 10).
