Remove keeps a lesson out of future prompts. It is not deleted — the decision survives re-saving the receipt it came from, and Restore reverses it at any time.

Pin holds a lesson in its store's prompt regardless of age. Pins fill first, so a pin costs a slot rather than making the prompt larger.

In use lists the corrections the next receipt would be sent: the newest for each store and receipt type, pinned ones first. All adds the older ones that have dropped out and any that were removed.

Recorded counts how many times this fix was made.

Sent this week and Last sent come from the prompt usage log, which starts from the day usage logging shipped — an older lesson can read never and still have been sent many times.

Came back counts how many times the same fix was needed again after it had already been sent. A correction that keeps coming back is not working and is worth removing.

Container deposit lines (CRV, bottle deposit) are a fee, not a product, and are left out of this page and of what is sent.

How many lessons one prompt carries is set by CORRECTION_PROMPT_LIMIT (default 10).
