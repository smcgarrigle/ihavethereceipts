TruePriceMemory

Connect to your local IHaveTheReceipts server

Server Connection

Default is http://127.0.0.1:8000 (works natively on Mac and via WSL2 localhost forwarding on Windows).

Generate a read-only token in Settings → TruePriceMemory Browser Extension.

Privacy & Security

  • Only the product title, size, barcode, and store name are sent to your local server.
  • Your token is read-only, stored locally in browser extension storage, and can be revoked in Settings at any time.
  • An offline snapshot of your item price summaries is cached locally so lookups continue working even when the server is stopped.
