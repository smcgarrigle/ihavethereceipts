# Project Context

This project is a Grocery Price Tracker built with Python (FastAPI), HTMX, and Alpine.js. 

For full technical context, architectural details, and project history, you MUST refer to the root [PROJECT_CONTEXT.md](file:///home/mcgar/projects/grocery-tracker/PROJECT_CONTEXT.md).

Key Stack:
- Backend: FastAPI, SQLAlchemy, Alembic
- Database: SQLite (file-based, zero-config)
- Frontend: Jinja2, Tailwind CSS, HTMX, Alpine.js
- OCR: Google Gemini API / local vision models
